Usage: boredealis [FLAGS]

Main usage:
    -i=, --input=       path to input file
    -o=, --output=      path to output file
    -f=, --filters=     number of filters desired
    -c=, --custom-model-path=
                        load a custom model. if someting goes wrong, it's your fault.

Other useful tidbits:
    -h, --help          prints this help message
    -v, --version       prints the version number, which for now is a cocky message
    -d, --debug         has the program print useful information
                           Sometimes too much information
    -r, --remove-tmp    does not remove the temporary directory on completion
    --remove-tmp=       sets the value of remove-tmp to true or false
    -rt                 same as -r
    -D, --disk          uses the disk to store images. Significantly slower than using RAM, but saves on memory
